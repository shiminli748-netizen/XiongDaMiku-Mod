# 熊出没之熊大快跑2018 - 初音未来Mod版

## 项目简介

本项目是对已停运游戏「熊出没之熊大快跑2018」的Mod修改版，将游戏中的「光头强」角色替换为初音未来。

## 修改内容

| 修改项 | 原版 | Mod版 |
|--------|------|-------|
| 角色名称 | 光头强 | 初音未来 |
| 角色贴图 | 光头强造型 | 初音未来VRM模型纹理 |
| 角色建模 | 男性体型 | 女性化比例（收窄肩膀、纤细腰部） |
| 游戏名称 | 熊大快跑 | 初音快跑 |

### 建模修改详情

通过修改Unity Mesh顶点数据，对光头强的3D模型进行了女性化改造：

- 肩膀收窄至78%（更窄的肩宽）
- 腰部纤细至72%（更细的腰围）
- 整体宽度收窄至88%（更纤细的体型）
- 头部缩小至92%（更精致的头型）
- 臀部区域保持92%（微调比例）

### 纹理替换详情

使用 GitHub 开源项目 [outrine/HatsuneMiku_VRM_Model](https://github.com/outrine/HatsuneMiku_VRM_Model) 提供的初音未来VRM模型，提取以下纹理并映射到光头强的UV空间：

- `body00.png` (1024x1024) - 身体贴图
- `face1.png` (1024x1024) - 脸部贴图
- `hair.png` (1024x1024) - 头发贴图
- `eye1.png` (512x512) - 眼睛贴图
- 完整贴图集 (2048x2048) - 全身纹理

替换了以下游戏内纹理文件：

- `Tex_guangtouqiang_02` (1024x1024 主纹理)
- `Tex_gtq_qiuyuanfu` (512x512 球员服)
- `Tex_gtq_chushi` (512x512 初始装)
- `Tex_gtq_jinsexie` (256x256 金色鞋)
- `Tex_gtq_chushixie` (256x256 初始鞋)

## 技术细节

- 游戏引擎：Unity 4.3.1f1
- 工具：UnityPy (Python) 用于纹理替换和Mesh修改
- Mesh修改：直接修改VertexData中的顶点坐标
- 签名：V1/V2/V3 签名方案
- APK大小：约82MB

## 安装说明

1. 卸载原版游戏
2. 下载Release中的APK文件
3. 允许未知来源安装
4. 安装Mod版APK
